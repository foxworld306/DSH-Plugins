## 1. 现在这个插件能做什么（按能力域汇总）

### 1.1 建 PPTX（两条路）

**A. SUEZ 模板模式**（`mode: "suez"`）
- 以公司官方模板为种子：母版、版式、主题、内嵌品牌字体全保留
- 23 个底座原型 + 6 个英雄页原型（共 29 种页面）
- 13 种原生图表（column / bar / line / area / stacked / stacked100 / pie / doughnut / radar / waterfall / combo / gantt / funnel）
- 表格：colspan / rowspan 合并、数字自动右对齐、换行策略、行高自适应
- 目录页克隆模板 Summary 版式：>4 章自动双列，>8 章续页并连续编号
- 演讲者备注：每页自动写来源 / 图注 / 许可 / 图表类型
- 每次构建自动跑：包完整性 → schema 校验 → 版式 lint → 节奏检查

**B. 自由发挥模式**（`mode: "free"`）
- 每页手写 HTML（1920×1080）→ 渲染成 2× 底图 + **真文本框**
- 三个内置皮肤：`editorial`（暖纸+深红）/ `tech`（深底+薄荷绿）/ `minimal`（纯白+单色）
- 皮肤自带母版与主题，**不需要 SUEZ 模板**
- 也可以完全不用皮肤：像「财报解剖」那 6 页一样，一页一稿

### 1.2 编辑已有文件（外科手术，不重建）

| 文件 | 支持的操作 |
|---|---|
| PPTX | 改文字（保字号/字体/颜色）、换图、改图表某系列数值、复制页、删除页 |
| DOCX | 改段落（文字匹配或序号）、改表格单元格、加批注、清洗修订/批注 |
| XLSX | 按坐标改单元格（保数字格式，新格继承列样式），支持写公式 |

统一规则：**永远写新文件**，拒绝覆盖输入；**包校验不过就不落盘**。

### 1.3 生成 Word / Excel / PDF

- **DOCX**：标题、副标题、章节、段落、项目符号、表格（深蓝表头 + 数字右对齐）、页眉页脚、A4 / A4 横向
- **XLSX**：多 sheet、冻结表头、text/number/int/percent、列宽、自动筛选、适宽打印、**真公式**（`calcPr fullCalcOnLoad` 保证打开即算）
- **PDF**：pptx / docx / xlsx 经 Office COM 导出；docx、xlsx 也能渲染成 PDF 来目检

### 1.4 读取与质检

- `suez_dump`：pptx（形状/字体/颜色/位置）、docx（段落/表格/页眉页脚）、xlsx（表名/行数/前 40 格）、pdf（页数/元信息）
- **批注读取**：docx 与 pptx 都会列出作者、日期、正文
- `suez_check`：任意 Office 文件的包门禁（Content_Types + rels + XML 良构）
- `suez_lint_deck`：几何越界、文字重叠、字号下限、对比度、文字密度、**页码定位**、**同图跨页**
- `suez_render_page`：真实 Office 渲染成 PNG / PDF

### 1.5 图片

- `suez_fetch_image`：按 URL 下载 + 记录来历（url / 日期 / 许可 / 作者 → `credits.json`）
- 超大图自动重编码到 1800px 宽（实测 603 KB → 118 KB）
- 裁切焦点 `focal: face | top | center`；统一圆角 `radius`
- 用了图却没写 `imageCredit` → 构建报警；同一张图多页复用只存一份

## 3. 相对 office-docs-win 1.0.1 的差异

| 能力 | office-docs-win 1.0.1 | dsh-suez-office 0.5.5 |
|---|---|---|
| 建 PPTX | 示例脚本手拼形状 | 29 种原型 + 13 图表 + 自动质检 |
| 建 DOCX / XLSX | 示例脚本 + 写作指南 | 声明式 spec，一条命令 |
| 修改已有文件 | 「dump 后手写 OOXML」 | 专用工具，按页/形状/单元格手术 |
| 读结构 | ✅ 4 种格式 | ✅ 同（并含批注） |
| 包校验 | ✅ | ✅ |
| 渲染 | ✅ | ✅ |
| 版式 lint / 节奏 | ❌ | ✅ |
| 原生图表 | ❌（手写 SVG 转 PNG） | ✅ 13 种可改数据 |
| Excel 公式 | 建表能写，改表无工具 | ✅ 建 + 改都支持 |
| 批注 | 只警告别弄坏 | ✅ 读 + 写（docx / pptx） |
| 修订清洗 | 文档里写「必须手工做」 | ✅ 一条命令 |
| 中文字体度量 / 避头尾 | ❌ 估算 | ✅ 真实 TTF + kinsoku |
