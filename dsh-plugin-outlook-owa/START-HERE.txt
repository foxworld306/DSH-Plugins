dsh-plugin-outlook-owa 0.5.2
让 DeepSeek Harness 读写你的 Outlook 邮件与日历
（复用你本机已登录的 OWA 网页会话：不需要密码、不需要 Graph API、不经过任何第三方服务器）

────────────────────────────────────────
怎么装（约 2 分钟）
────────────────────────────────────────
1. 把整个文件夹解压到本地路径，例如
      C:\tools\dsh-plugin-outlook-owa
   ※ 如果放在 OneDrive/网络盘上，请确认是"始终保留在此设备"，
     不要停在"仅在线"的占位文件状态（否则 node 读不到文件）。

2. 双击文件夹里的 install.cmd，等它跑完。
   它会自动：装进 DSH 的 profile / 写好配置 / 打开一个登录窗口。
   （不需要你编辑任何 yaml 文件。）

3. 在弹出的浏览器窗口里用公司账号登录 OWA，勾选"保持登录状态"。

4. 关掉 DSH，重新运行 dsh web。

5. 在会话里说一句："看看我今天的邮件"。

────────────────────────────────────────
它会打开哪个浏览器？
────────────────────────────────────────
自动跟随你的默认浏览器（Chrome / Edge / Brave / Vivaldi / Opera 都行）。
默认浏览器是 Firefox 的话，会自动改用你已经装了的 Chrome 或 Edge
（Firefox 的远程调试协议不同，插件驱动不了它）。

想确认这台机器上会拉起哪个浏览器，在文件夹里运行：
      node test-browser.mjs

────────────────────────────────────────
前提条件
────────────────────────────────────────
- Windows
- Node.js 20 或更新（https://nodejs.org/）
- 之前至少成功启动过一次 DSH（否则 profile 目录还没建出来）

────────────────────────────────────────
出问题怎么办
────────────────────────────────────────
- 提示"没找到 DSH 的 profile"
    → 先运行一次 dsh web，让它把 profile 建出来，再双击 install.cmd。

- 提示"拿不到 OWA 的访问令牌"
    → 在插件打开的那个浏览器窗口里点开任意一封邮件，然后重试。

- 提示"找不到 dsh 命令"
    → 先装 DSH：npm i -g @deepseek-ai/dsh

- 重复双击 install.cmd 是安全的：装包幂等、配置已存在就跳过、
  浏览器已在跑就不重开。插件更新后也只需重新双击一次。

更多细节见 README.md。
